⭐ 唯一开放的能力

游戏开发接口对外开放

本软件为闭源软件,但游戏插件开发完全开放。 一个文件夹、三个文件,就是一个能被平台加载、能被学生玩到、成绩能进排行榜的游戏。

插件长什么样

  • game.json —— 元数据:名称、图标、简介、人数、是否联机
  • static/index.html —— 游戏界面,平台自动放进页面里
  • server.py —— 服务端逻辑,联机游戏才需要

平台给你什么

  • 独立接口前缀:/api/game/<你的游戏>/…
  • 独立实时通信频道:/game/<你的游戏>,各游戏互不干扰
  • 成绩提交通路,写一次就进后台与排行榜
  • 学生姓名、房间、人数上限等基础能力现成可用
  • 放进目录 + 点「重新扫描」即上线,不用改平台任何代码

  "has_server": true,

# ② server.py —— 定义 Game 类即可
from games.base import BaseGame


class Game(BaseGame):

    def register_routes(self, bp):
        # 地址: /api/game/my_game/hello
        @bp.route("/hello")
        def hello():
            return {"ok": True}

    def register_socketio(self, socketio, namespace):
        # 频道: /game/my_game
        @socketio.on("join", namespace=namespace)
        def on_join(data):
            socketio.emit("joined", data, namespace=namespace)

安全设计

在学校网络里用得住

从登录到文件落盘,每一环都做了基本防护。

🛡️危险文件拦截

默认拦截 46 类可执行与脚本文件,阻断通过共享目录投放木马的最常见路径,管理员可自行调整。

🔐登录鉴权

学生登录与注册均需图形验证码;上传文件、提交成绩都必须先登录。

🔑身份校验

客户端连接时校验服务端身份,避免学生把数据交到冒充的服务器上。

🧱路径防护

下载路径做了穿越防护,无法借文件下载读取服务器上的其他内容。

🚦限速与配额

可限制上传下载速度、限制每人占用空间,保证多人同时使用时不被个别大文件拖垮。

👥权限分级

超级管理员与普通管理员分离,增删管理员等敏感操作仅超级管理员可执行。

常见问题

大家最常问的几件事

需要在一台电脑上装什么吗?
不需要。服务端是打包好的程序,目标电脑不用安装运行环境,整个文件夹拷过去双击启动即可。学生端只要有浏览器就能用,连浏览器都不用装额外的插件。
学生不在同一个局域网能用吗?
可以。把客户端文件夹和配置文件一起发给学生,运行客户端点「开始连接」,程序会自动组网并搜索服务端,整个过程不需要公网 IP,也不用在路由器上做端口映射。
能上传 exe 或压缩包吗?
可执行与脚本类文件(如 exe、bat、dll、ps1、jar 等,默认 46 类)会被自动拦截,以防在班级电脑之间传播木马。压缩包可以正常上传——如果确实需要传程序,压成压缩包再传即可。管理员也可在后台调整这份拦截清单。
每个学生能传多少东西?
单次上传不超过 100 MB,每人累计 300 MB。学生在首页删除自己以前上传的文件后,空间会立即释放。
学生的打字成绩怎么统计?
每次练习结束提交成绩后,速度、正确率、输错率、用时都会入库。管理员可在后台查看明细,并按考试或班级需要一键导出成 CSV 表格,直接用 Excel 打开。
能自己加游戏吗?
能,而且这正是本软件对外开放的能力。按公开的游戏开发接口写一个插件文件夹放进游戏目录,在后台点「重新扫描」就能上线,不需要修改平台本身。接口规范与示例见游戏开发指南。
能不能拿到源代码?
不能。本软件为闭源软件,不提供源代码与内部实现细节;对外开放的只有游戏插件开发接口。如需二次定制,请联系维护者。
杀毒软件报毒怎么办?
打包后的程序有时会被误判。把整个程序目录加入杀毒软件的信任区或白名单即可,注意不要只添加单个文件。
数据放在哪里?怎么备份?
账号、成绩、文件索引与共享文件都保存在程序目录下,首次运行时自动生成。定期把整个程序目录备份一份即可;恢复时保持目录结构不变整体替换。
